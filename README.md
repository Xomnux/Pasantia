# PASANTIA GERARD

## Descripcion
Se realizará comentarios de código de C# y se utilizarán las herramientas de dotnet,dotnet  docfx y git.

## Comandos
### Docfx
    - docfx init
    - docfx metadata
    - docfx build
    - docfx serve _site
### Git
    - git init
    - git add .
    - git commit -m "Añadir mensaje"
    - git push
    - git pull
    - git log
### Dotnet
    - dotnet new
    - dotnet run
