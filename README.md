# PASANTIA GERARD

## Descripcion
Se realizará comentarios de código de C# y se utilizarán las herramientas de dotnet, docfx (md:markdown language) y git. Se ejecutará el programa y se debuggeará mediante archivos de configuración (json) en VSCode.

### General (.NET SDK)
    - .net 10 runtime
    - dotnet
### VS Code
    - C# Extension
### Visual Sutido*
    - Desarrollo de escritorio .NET

## Comandos
### Docfx
    - docfx init
    - docfx metadata
    - docfx build
    - docfx serve _site
### Git
    - git init
    - git add .
    - git commit -m "Añadir mensaje"
    - git push
    - git pull
    - git log
### Dotnet
    - dotnet new
    - dotnet run

## Launch and debug
    - launch.json: ejecutar
    - task.json: tareas varias
### Run
    - Terminal->Run Task
    - Run->Start Debugging
